## 2.STFT帧的选择
选择依据：
1. 信号特征（FCS和VTS是否比较好的都识别到，是否对于背景无明显特征出现）《---不等式要求，视觉量化判据【其次】
2. 窗长消融（扫参选择准确率还ok的窗长）--》可解释性比较差【最后】
3. 搜集相关的论文来确定合适的窗长并简要验证下看下效果是否还ok---》论文选了哪些窗长呢？（🌙）【优先】
![信号的常见的特征](image-8.png)
![分辨率要满足的不等式](image-11.png)
![视觉和量化判据](image-12.png)
FCS：局部SNR大，但总体能量小
VTS：局部SNR小，但总体能量大
功率：VTS细节 < FCS弱跳频点 <  VTS边界 < FCS强跳频点主峰
根据实际的FCS和VTS的时间分辨率和频率分辨率来折中选择合适的帧长，或者作为多通道融合输入

![5ms下不同帧长的结果](../image/Q2/5ms/stft_sweep_compare.png)
以80MHZ作为采样率--》后续需要进行验证？发送指令是否出于2.4G频段（数据集要求的）
根据对比，选择2048作为帧长。
- 帧短--》频率分辨率低--》图片纵向分辨率低，横向分辨率高--》呈现竖线的感觉
- 帧长--》频率分辨率高--》图片纵向分辨率高，横向分辨率低--》呈现横线的感觉

## 6.假设
1. 预处理不会增加特征，只会降低或者维持特征
2. 噪声为加性噪声
3. 预处理方法对“信号+噪声”的影响是线性的
4. 视觉清晰程度可以由去噪后信噪比和特征保留程度来衡量。
